Hands-On 1, Task 1, Step 2 - notes on generated project files
================================================================
angular.json        - CLI workspace config: build/serve/test targets, budgets, styles/scripts entry points.
tsconfig.json        - Base TypeScript compiler options shared by app and spec configs.
tsconfig.app.json    - TypeScript config specific to the browser app build (extends tsconfig.json).
package.json         - npm package manifest: dependencies, devDependencies, and CLI scripts (start/build/test).
src/main.ts           - Application entry point; bootstraps the standalone AppComponent with appConfig.
src/app/app.config.ts - Standalone-API equivalent of AppModule; registers router, HttpClient, and NgRx store providers.
src/app/app.component.ts - Root component; hosts the header and <router-outlet> for the whole SPA.
src/index.html        - The single HTML shell page that hosts <app-root> and is served for every route.

Hands-On 1, Task 1, Step 5 - angular.json budgets
================================================================
Under architect > build > configurations > production > budgets:
  - initial bundle: maximumWarning 500kb, maximumError 1mb
  - anyComponentStyle: maximumWarning 4kb, maximumError 8kb
These thresholds fail or warn the production build if the compiled bundle / a
single component's stylesheet grows past the configured size, keeping the
app's load performance in check.
